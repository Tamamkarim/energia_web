##  Sovelluksen kuvaus

Projekti Enrgy on energian kulutuksen seurantajärjestelmä, jossa käyttäjät voivat:
- kirjautua sisään
- seurata energiankulutusta
- tallentaa tiedostoja
- käyttää reaaliaikaista dataa

---

##  Teknologiat

### Backend
- Node.js
- Express
- MariaDB / SQLite
- JWT Auth
- Multer + Cloudinary
- Socket.io

### Frontend
- React (Vite)
- Socket.io-client
